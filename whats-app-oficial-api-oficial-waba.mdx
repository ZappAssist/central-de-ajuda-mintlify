## 📱 Modo Coexistência (COEX)

Para operações que utilizam a conexão oficial integrada compatível, o modo **COEX (Coexistência)** permite que você **continue utilizando o aplicativo WhatsApp Business no celular** ao mesmo tempo em que a equipe atende pelo painel da **ZappAssist**.

<Warning>
  **Atenção:** o modo de coexistência possui limitações técnicas impostas pela própria Meta (como indisponibilidade para servidores de voz SIP dedicados). Verifique a compatibilidade antes de ativar.
</Warning>

## 💰 Recursos para Economizar Mensagens na API Oficial

Na API Oficial, a **Meta** realiza cobranças por conversas/mensagens iniciadas fora da janela gratuita de atendimento. Para ajudar sua empresa a reduzir esses custos sem abrir mão da segurança oficial, a **ZappAssist** oferece ferramentas exclusivas de economia:

### 1. Concatenador de Mensagens

Quando um atendente envia várias frases curtas em sequência (ex.: _"Olá!"_, _"Tudo bem?"_, _"Vou verificar seu pedido"_), o sistema **agrupa essas mensagens em um único envio**, evitando cobranças múltiplas desnecessárias na API Oficial.

### 2. Chat Externo por Link

Permite enviar um link seguro para que o cliente continue a conversa por uma interface web semelhante ao WhatsApp, mantendo o atendimento fluido sem gerar custos de mensagens oficiais a cada interação.

### 3. Gestão da Janela de 24 Horas e Templates

- **Janela de Atendimento (24h):** sempre que o cliente envia uma mensagem, abre-se uma janela de 24 horas para respostas livres da sua equipe.
- **Mensagens Modelo (Templates):** fora da janela de 24 horas, o sistema utiliza apenas templates pré-aprovados pela Meta para retomar o contato de forma segura e dentro das regras.

## 📋 Requisitos para Utilizar a API Oficial

Antes de conectar seu número oficial, certifique-se de possuir:

- Uma conta ativa no **Gerenciador de Negócios da Meta (Meta Business Suite)**;
- Um número de telefone válido que **não esteja vinculado** a outra conta de WhatsApp (ou elegível para migração/COEX);
- Um cartão de crédito internacional cadastrado na conta da Meta para pagamento direto das tarifas de conversas cobradas pela própria Meta (quando ultrapassada a franquia gratuita de respostas).
