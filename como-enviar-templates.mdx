## ✉️ Enviar Template pela Tela de Atendimento

Use esta opção para iniciar uma conversa ativa com um cliente ou retomar um atendimento cuja janela de 24 horas já foi encerrada.

Com o ticket aberto na tela de atendimento:

1. Clique no botão **“+”** (ao lado da caixa de digitação de mensagem);
2. Selecione a opção **Enviar Template**.

> 📸 **[INSERIR PRINT / IMAGEM 1]**<br />_Descrição do print:_ Menu de ações "+" na barra inferior do chat destacando a opção "Enviar Template".

### 1. Selecione a Categoria do Template

Escolha a categoria correspondente ao modelo cadastrado (ex.: _Utilidade_, _Marketing_ ou _Autenticação_).

> 📸 **[INSERIR PRINT / IMAGEM 2]**<br />_Descrição do print:_ Seletor de categoria do template na janela de envio.

### 2. Selecione o Template Desejado

Escolha na lista o nome do template aprovado que deseja utilizar.

> 📸 **[INSERIR PRINT / IMAGEM 3]**<br />_Descrição do print:_ Lista suspensa mostrando os templates sincronizados disponíveis para seleção.

### 3. Preencha os Campos e Envie

Ao selecionar o modelo, a **ZappAssist** exibirá:

- Uma **pré-visualização completa** de como o cliente receberá a mensagem;
- Os campos editáveis para preencher as variáveis dinâmicas (`{{1}}`, `{{2}}`, etc.).

> 📸 **[INSERIR PRINT / IMAGEM 4]**<br />_Descrição do print:_ Modal de preenchimento das variáveis do template com a pré-visualização da mensagem ao lado e o botão "Enviar".

Preencha os dados solicitados e clique em **Enviar**.

## 📣 Enviar Campanha (API Oficial)

Para disparar um template aprovado para uma lista de clientes de forma programada:

1. No menu lateral da **ZappAssist**, acesse o módulo **Campanhas**;
2. Clique na aba **API OFICIAL**;
3. Clique no botão **Adicionar** (ou _Nova Campanha_).

No formulário de criação, preencha:

- **Canal WhatsApp:** selecione o número oficial conectado;
- **Template:** escolha o modelo aprovado que será disparado;
- **Variáveis:** preencha os campos dinâmicos do template;
- **Nome da campanha:** identifique o disparo para seus relatórios;
- **Data e hora de início:** defina quando o envio deve começar;
- **Tempo entre mensagens:** configure o intervalo em segundos entre cada disparo.

> 📸 **[INSERIR PRINT / IMAGEM 5]**<br />_Descrição do print:_ Tela de cadastro de Campanha na aba "API Oficial" destacando a seleção do canal, template, variáveis e agendamento.

### 📋 Adicionar Contatos e Programar o Envio

Após salvar o cadastro inicial da campanha:

1. Localize a campanha na lista e clique no ícone **Listar contatos da campanha**;

> 📸 **[INSERIR PRINT / IMAGEM 6]**<br />_Descrição do print:_ Lista de campanhas destacando o botão/ícone de "Listar contatos da campanha".

2. Adicione ou importe os contatos que receberão a mensagem;
3. Retorne à tela principal de campanhas;
4. Clique em **Programar o envio** para iniciar os disparos no horário configurado.
